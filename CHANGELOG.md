# Changelog

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] — 2026-07-30

### Added
- Full e-commerce storefront with product browsing, filtering, and search
- Product detail pages with dynamic URL slugs (`/products/product-details/product-name`)
- Responsive Navbar with mobile menu, search bar, and category dropdown
- User authentication (register / login / logout) with JWT
- Shopping cart with add, update quantity, and remove functionality
- Wishlist system for logged-in users
- WhatsApp-based quote ordering system
- Admin dashboard for product & category management (CRUD with Cloudinary image uploads)
- User profile page with order/quote history
- About page with team section, timeline, showroom, and trust stats
- Contact page with hero banner, contact form, Google Maps embed, and FAQ accordion
- Responsive pagination (20/PC, 16/tablet, 12/mobile products per page)
- Smooth scroll-to-top on page navigation (Lenis integration)
- Sentry error tracking (frontend + backend)
- Express backend with MongoDB (Mongoose), Cloudinary, and Gmail SMTP
- Professional folder structure with controllers, services, validators, and error handling
